One line of comedy: the safety warning label that should come printed on every human being, at most 160 characters, funny first and plausible second.

> WARNING: This human runs on three hours of sleep, one cup of coffee, and the unshakable belief that whatever just went wrong is definitely not its fault.

## Run it

```sh
python3 main.py
```

The program writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It is deterministic: every run writes the same 153-character line.
